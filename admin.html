🔑 Answer Keys

Keys are stored privately in the database — candidates can never read them, and scoring is done on the server when they submit. Needed once per test set (IELTS and TOEIC).

1 — Choose the test set
2 — Enter the answers
One answer per line, as number: answer — e.g. 1: B, 2: TRUE, 6: MOVIE | FILM (use | to accept several alternative spellings). You can also paste a plain column of answers (one per line, no numbers) and they will be numbered 1, 2, 3… automatically. Matching ignores capital letters and extra spaces. Listening and Reading are numbered separately (1–40 for IELTS, 1–100 for TOEIC).

Publish to GitHub

Generate config JSON and upload to GitHub Pages for candidates to access.

Step 1 — Set Test Set Name
For TOEIC, keep the word "TOEIC" in the name — tests.html uses it to send candidates to the TOEIC test screen instead of the IELTS one.
Step 2 — Build your config

Questions are authored in the Question Makers. Use Download Config JSON there.

Step 3 — Upload to GitHub
  1. Go to your GitHub repository
  2. Open configs/ folder
  3. Click Add file → Upload files
  4. Upload the downloaded JSON file
  5. Commit changes
  6. Click the file → Click Raw → Copy the URL
Step 4 — Paste Raw URL & Save Test Set
