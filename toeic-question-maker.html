TOEIC Listening & Reading — Test Info
This is the standard TOEIC L&R format: 100 Listening questions (Parts 1–4) + 100 Reading questions (Parts 5–7), all multiple choice. No Writing or Speaking sections. Questions are numbered 1–100 (Listening) and 101–200 (Reading), matching the real test.
Bulk import via CSV
With 200 questions per test, an in-browser editor is much faster than adding items one by one via forms. Start blank and add rows, or upload a CSV first (Google Sheets/Excel export) and keep editing it here — either way, work autosaves as you type.

Download Config JSON
This produces a single JSON file for the whole test — same publish flow as the IELTS Question Maker:
  1. Click Download Config JSON below.
  2. In your GitHub repo, go to configs/TOEIC/ (create the folder if it doesn't exist) and upload the file.
  3. Click the uploaded file → Raw → copy that URL.
  4. In admin.html → Publish panel, paste the Raw URL, set Exam Type: TOEIC, and make sure the Test Set Name contains the word "TOEIC" (e.g. "TOEIC Mock Test 1") — tests.html uses that to route candidates to the TOEIC test screen instead of the IELTS one.
Send Answer Key to the Server
The config JSON you upload to GitHub is public, so — same as the IELTS side of this app — it should not contain the correct answers. Grading happens server-side instead: this sends the answer key to the protected answer-key table, keyed to a Test Set ID. (You can also paste or review it in admin.html → Answer Keys.)

Create the test set first in admin.html → Publish panel (so you have a Test Set ID to paste below), then come back here and click Send.
